# 🏠 Airbnb Data Analysis — Practice

This repository contains my hands-on practice with Python data analysis using an Airbnb dataset.

The main purpose of this practice was to understand the complete data-analysis workflow, from loading and cleaning raw data to performing exploratory data analysis and extracting basic insights.

## 🎯 Learning Objectives

Through this practice, I worked on:

- Understanding a real-world dataset
- Converting data types
- Selecting relevant columns
- Removing redundant columns
- Renaming columns
- Handling missing values
- Removing duplicate records
- Checking invalid values
- Detecting price outliers
- Verifying data quality
- Performing Exploratory Data Analysis (EDA)
- Creating visualizations
- Interpreting basic business insights

## 📊 Exploratory Data Analysis

The notebook explores:

- Price distribution
- Room type distribution
- Listings by neighbourhood group
- Price by room type
- Price by neighbourhood group
- Correlation between numerical variables

## 💡 Practice Insights

Some observations from the analysis include:

- Manhattan and Brooklyn contain the highest number of listings.
- Entire apartments are the dominant room type in the dataset.
- Airbnb prices show a wide distribution.
- Prices vary considerably within room types and neighbourhood groups.
- `number_of_reviews` and `reviews_per_month` show a relatively stronger correlation compared with most other numerical variables.
